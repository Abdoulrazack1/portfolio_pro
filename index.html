À propos

Abdoulrazack A. Lille, France · DWWM

En formation Développeur Web et Web Mobile, j'apprends à transformer des idées en interfaces solides — d'abord par le HTML/CSS, puis avec JavaScript, et plus récemment avec Node.js côté serveur.

Je suis arrivé au code par curiosité et par envie de fabriquer. Mes projets personnels sont mon vrai terrain d'entraînement : recopier ce qui m'inspire, comprendre comment ça fonctionne, puis ajouter ma propre version. C'est aussi simple que ça, et c'est ce qui me fait progresser le plus vite.

Mes goûts : un code lisible avant d'être malin, une UX qui ne fait pas perdre de temps, et des interfaces qui ont un peu de caractère. La pop culture japonaise — manga, design éditorial — influence souvent mes choix visuels.

  • i Lire la doc, écrire petit, livrer.
  • ii Un projet = une excuse pour apprendre une chose nouvelle.
  • iii Le bug n'est pas l'ennemi — c'est le prof.

/ Full-stack
Mission #01 · Flagship 2026

C.C. Salouel

Plateforme web complète pour un club de cyclisme : 19 pages, API REST avec rôles, base MySQL, génération automatique de courses depuis du scraping, GPX, profils altimétriques, météo et vue Street View synchronisée au tracé.

  • Architecture full-stack : front vanilla + Express + MySQL
  • Auth JWT + bcrypt avec 3 rôles (admin · modo · membre)
  • Pipeline auto-import : scraping → routing OSRM → élévation Open-Meteo → GPX
  • 32 sorties cataloguées, 272 POIs, profils altimétriques colorés par pente
  • Sécurité : helmet, rate-limit, validators, multer pour les uploads GPX
Node.js Express MySQL JWT Leaflet OSRM Scraping

/ ML / AI
Mission #03 · ML 2026

Logic-Lens

Intelligence artificielle qui déchiffre le « pourquoi » du code JavaScript. Un Transformer Encoder TensorFlow.js apprend à extraire l'invariant mathématique ou la formule logique sous-jacente à n'importe quelle fonction JS.

  • Pipeline ML complet : génération dataset → training → inference
  • ~3 025 paires code muté → formule via mutation AST
  • Transformer Encoder sur séquences AST (TensorFlow.js)
  • Interface web + API + bridge inter-moteurs (port 4000)
  • Analyse depuis fichier, snippet, URL ou repo entier

Mission #04 · Live 2026

Safari Frenzy

Mini-jeu de capture pixel art façon Game Boy, avec API de scores en Node.js. 60 secondes pour attraper un maximum de créatures sans toucher les BOOMb. Système de combo jusqu'à ×5, classement persistant, rendu Canvas hi-DPI.

  • Game loop Canvas + state machine en JavaScript vanilla
  • API REST Express avec persistance JSON et validation serveur
  • Sprites pixel art originaux dessinés en arrays (palette Game Boy)
  • Mécanique combo + risque/récompense (BOOMb réinitialise tout)
  • En cours : modes Endless/Hardcore/Hunt, power-ups, audio 8-bit, JWT anti-triche

Le parcours

La formation DWWM est découpée en étapes. Voici où j'en suis aujourd'hui, et ce qui suit.

  1. Étape 01 · Validée

    Fondations HTML & CSS

    Sémantique, mise en page Flexbox/Grid, responsive. Premières maquettes intégrées.

  2. Étape 02 · Validée

    Sites multi-pages & cohérence produit

    Architecture de fichiers, design system simple, parcours utilisateur du panier au paiement (Kinka, Peartech).

  3. Étape 03 · En cours

    JavaScript — DOM, logique, async

    Manipulation du DOM, événements, fetch d'API, premiers projets dynamiques. C'est l'étape actuelle du cursus.

  4. Étape 04 · Anticipée en autonomie

    Back-end Node.js, MySQL & authentification

    Express, REST, MySQL, JWT, bcrypt, validation, scraping et services externes — déjà mis en pratique sur Cycling, Js-Ranker et Safari Frenzy, en attendant le module officiel du cursus.

  5. Étape 05 · À venir

    Frameworks & écosystème moderne

    React, gestion d'état, build modernes. Objectif : transformer mes projets statiques en SPA.
